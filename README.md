# 🧑‍💻 Kang Minseo Portfolio

프론트엔드 개발자를 목표로 하는 강민서의 개인 포트폴리오 웹사이트입니다.
사용자가 쉽게 이해하고 편리하게 사용할 수 있는 웹서비스를 만드는 것을 목표로 제작했습니다.

🔗 **배포 링크**: [ms-portfolio-ashen.vercel.app](https://ms-portfolio-ashen.vercel.app/)

---

## 🛠️ 기술 스택

| 구분 | 사용 기술 |
| --- | --- |
| Design | Figma |
| Framework | Next.js |
| Language | TypeScript |
| Deploy | Vercel |

## 📂 주요 구성

- **소개 (About)** — 자기소개 및 관심 분야
- **학력 (Education)** — 학교, 학점, 교육/자격 사항
- **경력 (Career)** — 인턴 및 활동 이력
- **프로젝트 (Projects)** — 진행한 프로젝트 소개

## 🚀 실행 방법

```bash
# 저장소 클론
git clone https://github.com/sandy424/ms-portfolio.git
cd ms-portfolio

# 패키지 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속하면 확인할 수 있습니다.
