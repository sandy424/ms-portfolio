## 🙋‍♀️ 안녕하세요!

저는 **사용자의 입장에서 먼저 써 보는** 프론트엔드 개발자를 꿈꾸고 있어요.

- 🧸 &nbsp;처음 방문한 사람도 헷갈리지 않는 화면을 만들고 싶어요
- 💌 &nbsp;받은 피드백은 꼭 다음 결과물에 담아요
- 🗂️ &nbsp;함께 일하는 사람이 헷갈리지 않게 차곡차곡 정리해요
- ☀️ &nbsp;안 되는 이유보다 할 수 있는 방법을 먼저 찾아요

아직 배울 게 많지만, 어제보다 오늘 한 뼘 더 자라는 중이에요 🌱
**같이 일하고 싶은 동료**가 되는 그날까지 꾸준히 성장할게요!
